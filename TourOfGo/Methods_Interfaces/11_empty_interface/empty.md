# Пустой интерфейс (`interface{}`)

Пустой интерфейс `interface{}` — это контракт, в котором нет абсолютно никаких требований (описано ноль методов).

Если в прошлых примерах (например, для должности «Снайпер» или «Курьер») мы требовали наличия конкретного навыка, то пустой интерфейс — это вакансия, на которую берут вообще всех. Поскольку любой тип данных в языке имеет как минимум ноль методов, в пустой интерфейс можно положить **любое значение**: целое число, строку, структуру, слайс или логическую переменную.

Начиная с версии Go 1.18, в язык добавили ключевое слово `any`. Это просто короткий синоним (alias) для `interface{}`. Они работают абсолютно одинаково, но писать `any` гораздо быстрее, и код с ним выглядит чище.

## Где это используется

Пустые интерфейсы нужны в функциях, которые работают с неизвестными заранее типами данных. Самый яркий пример — функция `fmt.Print`. Создатели языка не могли знать, что именно вы захотите вывести на экран (число, текст или сложную структуру), поэтому функция принимает аргументы типа `any` и успешно "переваривает" абсолютно любые данные.

## Разбор кода по шагам:

* **Создание:** `var i interface{}`
Создает пустой "бейдж". Изначально в нем нет ни типа, ни значения `(nil, nil)`.
* **Первое присваивание:** `i = 42`
В переменную `i` кладут целое число. Под капотом интерфейс, который представляет собой пару из двух указателей (на тип данных и на само значение — `itab` и `data`), заполняется: тип становится `int`, а значение — `42`.


* **Второе присваивание:** `i = "hello"`
В ту же самую переменную кладут строку. Внутренняя структура интерфейса перезаписывается: тип меняется на `string`, а значение — на `"hello"`.
* **Функция `describe`:**
Выводит скрытую "коробочку" интерфейса на экран. Флаг `%v` печатает само значение (`data`), а флаг `%T` печатает конкретный тип (`itab`), который в данный момент лежит внутри интерфейса.
