Интерфейс Stringer в Go
Представь, что у каждого объекта в твоей программе может быть своя «визитная карточка». Когда ты просишь Go вывести объект на экран (например, через fmt.Println), язык по умолчанию просто выводит все его сырые данные в фигурных скобках, например: {Arthur Dent 42}.

Но что, если ты хочешь, чтобы объект выводился красиво, в понятном для человека формате? Для этого создатели языка добавили в стандартный пакет fmt интерфейс Stringer.

Как выглядит этот контракт
В пакете fmt зашит очень простой интерфейс:

Go
type Stringer interface {
    String() string
}
Он означает простое правило: «Если у объекта есть метод String(), который возвращает текст (string), значит, этот объект умеет сам себя описывать».

Пример использования на практике
Go
package main

import "fmt"

// 1. Создаем структуру
type Person struct {
	Name string
	Age  int
}

// 2. Учим структуру красиво описывать себя
func (p Person) String() string {
	return fmt.Sprintf("%v (%v years)", p.Name, p.Age)
}

func main() {
	a := Person{"Arthur Dent", 42}
	z := Person{"Zaphod Beeblebrox", 9001}
    
	// 3. Вывод на экран
	fmt.Println(a, z)
    // Результат: Arthur Dent (42 years) Zaphod Beeblebrox (9001 years)
}
Как это работает «под капотом» (Разбор по шагам)
Структура: Ты создаешь пользовательский тип данных Person, который объединяет в себе поля имени и возраста.

Свой формат: Ты привязываешь к типу Person метод String(). Внутри ты решаешь, что хочешь выводить данные по конкретному шаблону: "Имя (Возраст years)".

Неявная реализация: В Go реализация интерфейсов является неявной (implicit). Разработчику не нужно писать ключевые слова вроде implements. Если структура реализует все методы, указанные в интерфейсе, она автоматически считается его реализацией. Так как у Person появился нужный метод String(), структура автоматически стала Stringer'ом.

Магия при печати: Когда функция fmt.Println получает твою переменную, она не спешит печатать её как попало. Сначала она проверяет: "А реализует ли этот объект интерфейс Stringer?". Видя твой метод String(), функция вызывает его и выводит на экран именно тот красивый текст, который ты подготовил.

Краткий итог
Stringer — это стандартный и общепринятый способ в Go сказать программе: "Используй мой метод String(), когда захочешь превратить эту структуру в текст или вывести её на экран".
