# Указатели и получатели методов в Go

## Операторы `&` и `*`

Операторы связаны с указателями, но выполняют разные действия:

- `&x` берёт адрес переменной `x` и возвращает указатель на неё.
- `*T` в объявлении типа означает «указатель на `T`».
- `*p` в выражении получает значение, на которое указывает `p`.

```go
v := Vertex{3, 4}
p := &v         // p имеет тип *Vertex
value := *p     // value — значение Vertex по адресу p
```

Для указателей на структуры Go автоматически разыменовывает указатель при доступе к полям: `p.X` можно использовать вместо `(*p).X`.

## Методы с указателем-получателем

```go
func (v *Vertex) Scale(f float64) {
    v.X *= f
    v.Y *= f
}
```

Получатель `*Vertex` означает, что метод работает с указателем на `Vertex`. Поэтому он может изменить исходную структуру.

```go
v := &Vertex{3, 4}
v.Scale(5)
```

После вызова координаты становятся `(15, 20)`. Вызов `v.Scale(5)` работает, потому что `v` уже указатель.

Go также позволяет вызвать метод с указателем-получателем для адресуемой переменной-значения:

```go
var v Vertex
v.Scale(5) // Go автоматически воспринимает это как (&v).Scale(5)
```

Это удобство относится к вызову метода. Для обычной функции, принимающей `*Vertex`, адрес нужно передать явно: `ScaleFunc(&v, 5)`.

## Выбор получателя: значение или указатель

Указатель-получатель обычно выбирают, когда:

1. метод должен изменить исходное значение;
2. нужно избежать копирования большой структуры при вызове.

Получатель-значение получает копию и подходит, если метод только читает данные и структура небольшая.

Метод `Abs` из примера только вычисляет длину вектора, но у него тоже указатель-получатель:

```go
func (v *Vertex) Abs() float64 {
    return math.Sqrt(v.X*v.X + v.Y*v.Y)
}
```

Это допустимо. Обычно для методов одного типа придерживаются единого подхода и не смешивают указательные и значимые получатели без причины.

## Разбор примера `Vertex`

```go
v := &Vertex{3, 4}
fmt.Printf("Before scaling: %+v, Abs: %v\n", v, v.Abs())
v.Scale(5)
fmt.Printf("After scaling: %+v, Abs: %v\n", v, v.Abs())
```

`v` — указатель на вершину. До масштабирования координаты равны `(3, 4)`, а `Abs` возвращает `√(3² + 4²) = 5`. После `Scale(5)` координаты равны `(15, 20)`, длина — `√(15² + 20²) = 25`.

Формат `%+v` показывает имена полей. Поскольку `v` является указателем, перед структурой отображается `&`.
