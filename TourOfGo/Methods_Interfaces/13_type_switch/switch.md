Type switches (Переключатель типов)
Представь, что к тебе на почтовый склад по конвейеру едут те самые "непрозрачные картонные коробки" (пустые интерфейсы interface{}), внутри которых может лежать абсолютно всё: числа, текст, булевы значения.

В прошлом примере мы учились аккуратно спрашивать коробку: "Там лежит строка?" (используя ok := i.(string)).
Но что, если мы ждем 5 или 10 разных вариантов содержимого и с каждым нужно поступить по-своему? Писать 10 проверок if ... else if ... подряд будет очень долго и код получится громоздким.

Для этого в Go придумали Type switch — эдакий умный сканер на сортировочной ленте.

Как это работает?
Вместо того чтобы пытаться угадать конкретный тип, ты отправляешь интерфейс в сканер:
switch v := i.(type)

Слово type здесь — это специальная команда. Сканер сам заглядывает внутрь интерфейса, читает его скрытый ярлычок (ту самую информацию о типе itab) и автоматически направляет посылку в нужный отсек (case).

Разбор твоего кода по шагам
У нас есть функция do(i interface{}), которая готова принять любой тип данных.

Go
switch v := i.(type) {
В этой строке происходит магия. Программа достает значение из интерфейса i и кладет его в новую переменную v. Главная фишка: тип переменной v будет автоматически подстраиваться под тот блок case, в который она попадет!

case int:
Если сканер увидел целое число, срабатывает этот блок. Внутри этого блока Go на 100% уверен, что переменная v имеет тип int. Именно поэтому мы можем применять к ней математику и умножать на два (v * 2).

case string:
Если в коробке лежал текст, срабатывает этот блок. Здесь переменная v официально считается строкой (string). Поэтому мы можем измерить её длину с помощью встроенной функции len(v). (Попытка вызвать len() у числа привела бы к ошибке, но умный switch нас защищает).

default:
Отсек для "всего остального". Если приехало что-то, для чего мы не написали отдельный case (например, логическое значение true), оно попадает сюда. Здесь v остается всё тем же абстрактным интерфейсом, с которым пришло, и программа просто печатает, что не знает, как с ним работать.

Что происходит в функции main:
do(21) — сканер видит число. Перенаправляет в case int. Программа выводит: Twice 21 is 42.

do("hello") — сканер видит текст. Перенаправляет в case string. Программа выводит: "hello" is 5 bytes long.

do(true) — сканер видит тип bool. Специального отсека нет, поэтому перенаправляет в default. Программа выводит: I don't know about type bool!

Краткий итог для новичка:
Type switch — это красивый и безопасный способ "распаковать" интерфейс, если внутри могут оказаться самые разные типы данных. Вместо длинной цепочки if-else, ты пишешь элегантный переключатель, который сам распределяет данные по нужным "полочкам" и меняет тип переменной так, чтобы с ней было удобно работать.
