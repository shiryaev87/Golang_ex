# Методы в Go

В Go нет классов, но методы можно объявлять для типов. Метод похож на функцию, но у него есть **получатель** (*receiver*) — значение, для которого вызывается метод.

## Метод структуры

```go
type Vertex struct {
    X, Y float64
}

func (v Vertex) Abs() float64 {
    return math.Sqrt(v.X*v.X + v.Y*v.Y)
}
```

В объявлении `func (v Vertex) Abs() float64`:

- `v` — имя получателя внутри метода;
- `Vertex` — тип получателя;
- `Abs` — имя метода;
- `float64` — тип результата.

Вызов `v.Abs()` вызывает метод для значения `v`. Для `Vertex{3, 4}` он вычисляет длину вектора: `√(3² + 4²) = 5`.

Получатель `Vertex` — значимый, поэтому метод получает копию значения. Это удобно, когда метод только читает поля. Чтобы менять исходное значение, обычно используют указатель-получатель, например `func (v *Vertex) Scale(...)`.

## Метод собственного числового типа

Метод можно объявить и для типа, основанного не на структуре:

```go
type MyFloat float64

func (f MyFloat) Abs() float64 {
    if f < 0 {
        return float64(-f)
    }
    return float64(f)
}
```

`MyFloat` — новый именованный тип на основе `float64`, а не псевдоним. Метод возвращает модуль числа. Например, `MyFloat(-math.Sqrt2).Abs()` возвращает положительное значение, примерно `1.4142`.

Преобразование `float64(...)` в теле метода приводит значение типа `MyFloat` к типу результата `float64`.

## Ограничение на тип получателя

Метод можно объявить только для типа, определённого в том же пакете. Нельзя добавить метод непосредственно к типу из другого пакета или к встроенному типу, например `int` или `float64`. Для этого можно определить собственный тип, как `MyFloat`.

## Метод и функция

В примере с `Vertex` функцию

```go
func Abs(v Vertex) float64
```

можно вызвать как `Abs(v)`, а метод

```go
func (v Vertex) Abs() float64
```

— как `v.Abs()`. Метод связывает операцию с типом получателя.
