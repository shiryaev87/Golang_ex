# Перебор слайса с помощью `range`

Программа заполняет слайс первыми десятью степенями двойки, а затем выводит их — по одному числу на строку.

```go
package main

import "fmt"

func main() {
	pow := make([]int, 10)
	for i := range pow {
		pow[i] = 1 << uint(i)
	}

	for _, value := range pow {
		fmt.Printf("%d\n", value)
	}
}
```

## Создание слайса

```go
pow := make([]int, 10)
```

`make([]int, 10)` создаёт слайс типа `[]int` длины 10. Все элементы вначале равны нулю — нулевому значению типа `int`.

## Заполнение слайса

```go
for i := range pow {
	pow[i] = 1 << uint(i)
}
```

При использовании `range` только с одной переменной для слайса эта переменная получает индекс элемента. В данном случае `i` последовательно принимает значения от `0` до `9`, и по этому индексу программа записывает результат в `pow`.

Оператор `<<` выполняет побитовый сдвиг влево. Число `1 << i` равно `2` в степени `i`: например, `1 << 0` равно `1`, `1 << 1` — `2`, `1 << 2` — `4`. `uint(i)` преобразует индекс к беззнаковому целому типу для использования в качестве величины сдвига.

После заполнения слайс содержит:

```text
[1 2 4 8 16 32 64 128 256 512]
```

## Вывод элементов

```go
for _, value := range pow {
	fmt.Printf("%d\n", value)
}
```

При переборе слайса через `range` можно получить индекс и значение. Здесь индекс не нужен, поэтому вместо него указано `_` — специальный идентификатор, который игнорирует значение. Переменная `value` получает элементы слайса по очереди.

`fmt.Printf` выводит значение по формату: `%d` означает десятичное целое число, а `\n` переводит вывод на следующую строку.

## Результат

```text
1
2
4
8
16
32
64
128
256
512
```
