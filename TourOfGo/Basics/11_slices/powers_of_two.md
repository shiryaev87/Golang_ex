# Степени двойки в слайсе

Программа создаёт слайс из десяти целых чисел, заполняет его степенями двойки и выводит каждое значение на отдельной строке.

```go
package main

import "fmt"

func main() {
	pow := make([]int, 10)
	for i := range pow {
		pow[i] = 1 << uint(i) // == 2**i
	}
	for _, value := range pow {
		fmt.Printf("%d\n", value)
	}
}
```

## Разбор

```go
pow := make([]int, 10)
```

`make` создаёт слайс `pow` длины 10. Все его элементы изначально равны нулю — это нулевое значение для типа `int`.

```go
for i := range pow {
```

При переборе слайса через `range` в переменную `i` записывается индекс очередного элемента. Здесь индексы идут от `0` до `9`.

```go
pow[i] = 1 << uint(i)
```

Оператор `<<` сдвигает двоичное представление числа `1` влево на `i` разрядов. Такой сдвиг равносилен умножению на `2` в степени `i`: `1 << i` — это `2^i`. Преобразование `uint(i)` задаёт количество сдвигов как беззнаковое целое число.

Например:

| `i` | Выражение | Значение |
|---:|---|---:|
| 0 | `1 << 0` | 1 |
| 1 | `1 << 1` | 2 |
| 2 | `1 << 2` | 4 |
| 3 | `1 << 3` | 8 |

После первого цикла слайс содержит `[1 2 4 8 16 32 64 128 256 512]`.

```go
for _, value := range pow {
	fmt.Printf("%d\n", value)
}
```

Во втором цикле `value` получает очередной элемент слайса. Индекс не нужен, поэтому вместо него используется `_` — специальный идентификатор для игнорирования значения. Формат `%d` выводит целое число, а `\n` переводит вывод на новую строку.
