# Упражнение: изображение из слайсов

Нужно реализовать `Pic(dx, dy)`, которая возвращает двумерный слайс `[][]uint8`. Внешний слайс задаёт строки изображения, а каждый внутренний слайс содержит значения пикселей одной строки. Значения `uint8` используются как оттенки серого или синего.

## Пример реализации

```go
package main

import "golang.org/x/tour/pic"

func Pic(dx, dy int) [][]uint8 {
	picture := make([][]uint8, dy)

	for y := range picture {
		picture[y] = make([]uint8, dx)
		for x := range picture[y] {
			picture[y][x] = uint8((x + y) / 2)
		}
	}

	return picture
}

func main() {
	pic.Show(Pic)
}
```

## Как устроен результат

Например, при `dx == 3` и `dy == 2` функция должна вернуть слайс из двух строк, каждая длиной три:

```text
[][]uint8{
	{0, 0, 1},
	{0, 1, 1},
}
```

Внешний слайс создаётся выражением `make([][]uint8, dy)`. Он содержит `dy` элементов, каждый из которых имеет тип `[]uint8`. Сначала эти внутренние слайсы равны `nil`, поэтому в цикле для каждой строки отдельно создаётся слайс пикселей:

```go
picture[y] = make([]uint8, dx)
```

Это важно: упражнение требует выделить каждый внутренний `[]uint8` в цикле. В результате у каждой строки есть собственный слайс длины `dx`.

## Заполнение пикселей

`range picture` перебирает индексы строк (`y`), а `range picture[y]` — индексы столбцов (`x`). Пиксель записывается по координатам `[y][x]`:

```go
picture[y][x] = uint8((x + y) / 2)
```

Формула `(x+y)/2` задаёт значение пикселя на основе его координат. Она создаёт плавно меняющийся узор. Преобразование `uint8(...)` переводит результат типа `int` в 8-битное беззнаковое целое — тип значений, который требует сигнатура результата.

Можно выбрать другую формулу, например `x*y` или `x^y`. Значения `uint8` находятся в диапазоне от 0 до 255; если результат преобразования выходит за этот диапазон, сохраняются младшие 8 бит.

## Передача функции в `pic.Show`

`pic.Show(Pic)` передаёт функцию `Pic` в визуализатор Tour of Go. Визуализатор вызывает её с размерами изображения и отображает возвращённые значения как цветовые уровни пикселей.
