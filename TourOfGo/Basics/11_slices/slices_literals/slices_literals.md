# Литералы слайсов в Go

Литерал слайса похож на литерал массива, но длина не указывается в квадратных скобках:

```go
[3]bool{true, true, false} // массив типа [3]bool
[]bool{true, true, false} // слайс типа []bool
```

В литерале массива число `3` задаёт фиксированную длину и входит в тип. В литерале слайса длина определяется количеством перечисленных элементов. В примере она равна `3`. Слайс ссылается на область памяти с этими значениями; сам слайс содержит описание этой области, а не отдельную копию элементов.

## Разбор примера

```go
q := []int{2, 3, 5, 7, 11, 13}
```

Создаётся слайс типа `[]int` из шести целых чисел.

```go
r := []bool{true, false, true, true, false, true}
```

Создаётся слайс типа `[]bool` из шести логических значений.

```go
s := []struct {
	i int
	b bool
}{
	{2, true},
	{3, false},
	{5, true},
	{7, true},
	{11, false},
	{13, true},
}
```

Здесь создаётся слайс структур. Тип структуры объявлен прямо в типе слайса и содержит поля `i` типа `int` и `b` типа `bool`. Значения полей в элементах указаны по порядку: сначала `i`, затем `b`. Например, `{2, true}` означает `i = 2` и `b = true`.

Поскольку тип переменной выводится из литерала, отдельно объявлять переменные `q`, `r` и `s` заранее не нужно.

Вызовы `fmt.Println` выведут значения слайсов примерно так:

```text
[2 3 5 7 11 13]
[true false true true false true]
[{2 true} {3 false} {5 true} {7 true} {11 false} {13 true}]
```
