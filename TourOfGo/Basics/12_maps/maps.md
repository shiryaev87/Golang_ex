# Конспект: Maps в Go

## Что такое map

`map` — коллекция пар «ключ → значение». По ключу можно сохранить или получить соответствующее значение.

Тип map записывается как `map[тип_ключа]тип_значения`. Например:

```go
map[string]int
```

Здесь ключи имеют тип `string`, а значения — тип `int`.

## Создание map

Нулевое значение map — `nil`. Из `nil`-карты можно читать: чтение вернёт нулевое значение типа элемента. Но добавлять в неё записи нельзя — это вызовет ошибку времени выполнения.

```go
var counts map[string]int // nil map
```

Чтобы создать карту, готовую к записи, используют `make`:

```go
counts := make(map[string]int)
counts["go"] = 1
```

## Map и структуры

Карта может хранить структуры в качестве значений:

```go
type Vertex struct {
    Lat, Long float64
}

locations := make(map[string]Vertex)
locations["Bell Labs"] = Vertex{40.68433, -74.39967}
```

В этом примере ключ — название места (`string`), значение — структура `Vertex` с широтой и долготой.

## Литерал map

Литерал создаёт и сразу заполняет карту. Для каждой записи указывают ключ и значение:

```go
locations := map[string]Vertex{
    "Bell Labs": {40.68433, -74.39967},
    "Google":    {37.42202, -122.08408},
}
```

Тип `Vertex` внутри значений можно не повторять: он уже указан в типе карты. В многострочном литерале после последнего элемента тоже ставят запятую.

## Чтение, добавление и обновление

```go
locations["Bell Labs"] = Vertex{40.68433, -74.39967} // добавить или заменить
place := locations["Bell Labs"]                      // прочитать
```

Присваивание по новому ключу добавляет запись, а по существующему — обновляет её.

Если ключа нет, чтение вернёт нулевое значение типа элемента. Например, для `map[string]int` это `0`.

## Удаление записи

```go
delete(locations, "Bell Labs")
```

`delete` удаляет запись по ключу. Если такого ключа нет, ничего не произойдёт.

## Проверка наличия ключа

Чтобы отличить отсутствующий ключ от ключа, которому соответствует нулевое значение, используют чтение с двумя результатами:

```go
value, ok := counts["go"]
```

- `value` — значение элемента или нулевое значение, если ключа нет;
- `ok` — `true`, если ключ присутствует, и `false`, если отсутствует.

Например:

```go
counts := make(map[string]int)
value, ok := counts["go"]
fmt.Println(value, ok) // 0 false
```

## Упражнение: подсчёт слов

`strings.Fields` разбивает строку на слова по пробельным символам. Для подсчёта создают карту, где ключ — слово, а значение — количество его появлений:

```go
func WordCount(s string) map[string]int {
    counts := make(map[string]int)
    for _, word := range strings.Fields(s) {
        counts[word]++
    }
    return counts
}
```

При первом обращении к новому ключу значение типа `int` равно `0`, поэтому `counts[word]++` увеличивает его до `1`. Повторные вхождения увеличивают счётчик дальше.

`wc.Test(WordCount)` — функция из пакета `golang.org/x/tour/wc`. Она вызывает переданную `WordCount` с тестовыми строками и сообщает, прошли ли проверки.
