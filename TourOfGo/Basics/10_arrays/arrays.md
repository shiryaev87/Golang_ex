# Массивы и слайсы в Go

В Go массив и слайс — разные типы. Массив имеет фиксированную длину, а слайс позволяет работать с последовательностью элементов переменной длины.

## Массивы

Длина массива указывается в квадратных скобках и является частью его типа:

```go
var a [3]int // массив из 3 элементов типа int
```

Можно попросить Go определить длину по количеству элементов:

```go
a := [...]int{10, 20, 30} // тип [3]int
```

Массивы разной длины — разные типы: `[3]int` и `[4]int` несовместимы. Длина массива не меняется.

## Слайсы

У слайса длина не записывается в тип:

```go
s := []int{10, 20, 30} // слайс из int
```

К слайсу можно добавлять элементы с помощью `append`. Результат нужно присвоить обратно: при необходимости `append` выделяет новую область памяти и возвращает слайс, указывающий на неё.

```go
s = append(s, 40)
```

## Слайс и массив

Слайс может ссылаться на часть массива. Изменения его элементов отражаются в исходном массиве:

```go
a := [4]int{10, 20, 30, 40}
s := a[1:3] // элементы с индексами 1 и 2: [20 30]

s[0] = 99
fmt.Println(a) // [10 99 30 40]
```

У слайса есть длина и вместимость:

```go
fmt.Println(len(s)) // 2 — количество элементов в слайсе
fmt.Println(cap(s)) // 3 — вместимость от начала слайса до конца массива
```

## Передача и копирование

При присваивании массива или передаче его в функцию копируются все его элементы. Слайс при присваивании или передаче копирует небольшой дескриптор, который указывает на область данных. Поэтому изменение элементов обычно видно через другие слайсы, указывающие на те же данные.

Если `append` выделил для слайса новую область памяти, изменения после этого добавления уже не относятся к прежнему массиву или другим слайсам.

```go
func changeArray(a [3]int) {
	a[0] = 99 // изменяется копия массива
}

func changeSlice(s []int) {
	s[0] = 99 // изменяется общий элемент
}
```

## Краткое сравнение

| | Массив | Слайс |
|---|---|---|
| Запись типа | `[3]int` | `[]int` |
| Длина | Фиксированная, входит в тип | Может меняться |
| Добавление элементов через `append` | Нет | Да |
| При передаче в функцию | Копируются все элементы | Копируется дескриптор; элементы обычно общие |

В большинстве случаев для последовательностей элементов используют слайсы. Массивы подходят, когда размер должен быть фиксированным.
