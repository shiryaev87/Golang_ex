# Функции как значения и замыкания в Go

## Функции как значения

В Go функции можно присваивать переменным, передавать другим функциям как аргументы и возвращать из функций.

Тип функции описывает типы её параметров и результата. Например:

```go
func(float64, float64) float64
```

означает функцию, которая принимает два значения `float64` и возвращает одно значение `float64`.

```go
func compute(fn func(float64, float64) float64) float64 {
	return fn(3, 4)
}
```

`compute` принимает функцию `fn` и вызывает её с аргументами `3` и `4`.

Функцию можно сохранить в переменной:

```go
hypot := func(x, y float64) float64 {
	return math.Sqrt(x*x + y*y)
}
```

`hypot` вычисляет гипотенузу прямоугольного треугольника по теореме Пифагора:

- `hypot(5, 12)` вычисляет `√(5² + 12²) = √169 = 13`;
- `compute(hypot)` вызывает `hypot(3, 4)`, поэтому получает `√(3² + 4²) = √25 = 5`.

Можно передать другую функцию с подходящим типом. Например, `math.Pow` возводит первое число в степень второго:

```go
compute(math.Pow) // math.Pow(3, 4) = 81
```

## Замыкания

**Замыкание** — это функция, которая обращается к переменной, объявленной вне тела этой функции. Замыкание сохраняет связь с такой переменной и может читать или изменять её даже после того, как внешняя функция завершилась.

```go
func adder() func(int) int {
	sum := 0
	return func(x int) int {
		sum += x
		return sum
	}
}
```

Внутренняя анонимная функция — это замыкание:

```go
func(x int) int {
	sum += x
	return sum
}
```

Переменная `sum` объявлена снаружи, внутри `adder`, но замыкание продолжает её использовать и обновлять при каждом вызове.

## Независимое состояние замыканий

```go
pos, neg := adder(), adder()
```

Здесь `adder()` вызывается два раза. Каждый вызов создаёт своё замыкание со своей отдельной переменной `sum`, изначально равной нулю:

- `pos(i)` прибавляет `i` к сумме `pos`;
- `neg(-2*i)` прибавляет `-2*i` к отдельной сумме `neg`.

В цикле `i` принимает значения от `0` до `9`. После каждой итерации `i++` увеличивает его на единицу:

```go
for i := 0; i < 10; i++ {
	fmt.Println(pos(i), neg(-2*i))
}
```

Например, при `i == 3`:

- `pos(3)` добавляет `3` к своей предыдущей сумме `3` и возвращает `6`;
- `neg(-6)` добавляет `-6` к своей предыдущей сумме `-6` и возвращает `-12`.

Результат всего цикла:

```text
0 0
1 -2
3 -6
6 -12
10 -20
15 -30
21 -42
28 -56
36 -72
45 -90
```

Важно: `pos` и `neg` не начинают суммирование заново при каждом вызове. Каждое замыкание сохраняет и обновляет собственное значение `sum`.
